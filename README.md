# Защищенный pipeline

Учебный проект, демонстрирующий построение защищённого CI/CD пайплайна для Python/FastAPI-приложения на GitLab CI. 

Пайплайн включает SAST, сканирование секретов, SCA и binary SCA, а также DAST. В качестве SAST инструмента используется semgrep, для секретов gitleaks, для SCA на обоих проверках trivy, для DAST zap.
## Архитектура пайплайна

Пайплайн построен по принципу **shift-left**: как можно больше проверок выполняется до сборки образа, чтобы как можно раньше обнаружить уязвимости. Все docker образы закреплены для воспроизводимости. Для большей безопасности они также должны поступать из локального docker hub, куда они должны попадать уже после проверок и подписи. Сам итоговый образ приложения также должен подписываться и отправляться туда, но разворачивать hub у себя я уже не стал.
Все проверки могут заблокировать пайплайн, но только в случае CRITICAL или HIGH уязвимостей.
Во время сборки и проверки после неё я старался избежать использования DinD, так как это требует привилегированного контейнера на самом раннере, но во время проверок сделать этого не удалось. Но использовался хотя бы rootless dind образ.
Сам гитлаб и раннер были развернуты локально.
У trivy при сканировании образа было много сработок. Они все были обработаны, просмотрены и подавлены через .trivyignore
